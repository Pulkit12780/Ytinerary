# Archived docs — superseded

These documents are kept for historical reference only. **They no longer describe the current app** — do not build from them.

## Why archived

### Design specs (`v2.0 | Uber Design Language | 2026-05-28`)
- `design-spec.md` (master) · `design-output.md` · `design-tokens-spec.md` · `components-spec.md` · `landing-page-spec.md` · `results-page-spec.md` · `motion-a11y-spec.md`

These describe the original **Uber-inspired** visual language (bold black, Uber green, Manrope). On **2026-06-13** the app was redesigned to a **warm editorial-travel** direction (Fraunces + Inter display/UI, a single clay `#C85A3C` accent, warm-paper `#FAF8F4` surfaces, real Unsplash photography). The current design lives directly in `index.html` and `results.html`.

### `dev-plan.md` (2026-05-28)
Early epic breakdown that names a stack we no longer use — Claude Haiku, Foursquare Places, scikit-learn k-means clustering, glassmorphism hero. The shipped backend uses **OpenAI gpt-4o-mini**, **OpenTripMap/Nominatim** geocoding, and a **stdlib distance-based judge** (no scikit-learn). All four epics shipped.
